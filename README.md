# Cloud Deployment Lab

A hands-on project focused on deploying and managing a Node.js application on an Ubuntu server.

## Technologies

- Node.js
- Express
- SQLite
- Ubuntu Server
- systemd
- Nginx
- HTTPS
- Git/GitHub

## Goals

- Build a simple web application
- Deploy it on an Ubuntu server
- Configure systemd as a service manager
- Configure Nginx as a reverse proxy
- Enable HTTPS
- Implement backup and restore
- Document the deployment process
